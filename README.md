## Dependencias Ollama (clasificador de correos)
Elimina packge.json y packge-lock.json e instala las dependencias necesarias.

1. Dirigite a la carpeta Ollama y copia en la terminal npm init -y
2. Escribe en la terminal npm i express
3. Escribe en la terminal npm install cors
4. Escribe en la terminal npm i node-fetch
5. por ultimo escribe node server.js para abrir el servidor

## Iniciar el n8n (servidor)
1. Dirigite al n8n y presiona publish (verifica que el modulo Get Mails tenga tenga en Responde data All entries)
